# Combat-Robot
Personal passion project, I am designing and building a combat robot for competition in my local league.

I've chosen a horizontal spinner as the weapon class, and I am using standard N20 DC motors to drive.
The microcontroller is a malenki-nano, which is an Australian made integrated receiver and ESC. 

I have a 300mAh battery, which fits nicely in the chassis under the controller.
I am currently designing armour to meet impact specifications.

The bot can be driven right side up and also upside down, which allows for flip protection.
